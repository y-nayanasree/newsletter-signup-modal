# 💌 Newsletter Signup Modal

A responsive newsletter signup popup built using HTML, CSS, and JavaScript.

## Features

- Automatically appears after 3 seconds.
- Can be opened using the Subscribe Now button.
- Close button, overlay click, and Escape key support.
- Email input with validation.
- Success message after valid input.
- Responsive layout for desktop and mobile.

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

- `index.html` — Page and modal structure
- `style.css` — Modal design and responsive styles
- `script.js` — Timer, modal controls, and email validation

## How to Use

1. Open the page and wait 3 seconds for the modal.
2. Enter a valid email address.
3. Click Subscribe to see the confirmation message.
4. Close the modal using the close button, outside overlay, or Escape key.

Note: This is a front-end demonstration. It validates the email but does not store addresses or send newsletters to a server.
